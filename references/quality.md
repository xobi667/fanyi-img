# xobi-img 质量验收

## 单图通用验收

- 用户要求的变化已完成，未指定区域保持。
- 主体完整，无多余部件、畸变、错误透视、异常阴影或反射。
- 比例、尺寸、格式和透明通道符合明确要求。
- 没有未要求的文字、Logo、水印、角标或伪字。
- 原图未覆盖；成品路径与 manifest 一致。
- 必须视觉查看本地成品，不能只检查文件存在和脚本返回码。

## 文字与 localization

- 逐字检查语言、拼写、大小写、标点、数字、币种、型号、单位和换行。
- 源图文字块一一对应，没有漏译、重复、新增、乱码或伪字。
- 商品、人物、Logo、背景、布局、颜色和促销结构没有漂移。
- 商品无拉宽、压扁、变窄、拉长或局部变形。
- 文字无压缩、拉伸、粘连、重叠、裁切、溢出或扭曲。
- 1:1 既有翻译规格才检查 800×800 JPG、900–1024KB；其他任务按用户要求。

## 批量完整性

必须核对：

```text
成功 + 跳过 + 失败 == 应处理数
每个 task_id 只出现一次、只归属一个 worker、只对应一个输出
manifest.json、report.md 与磁盘文件一致
没有漏图、重复、覆盖、错配参考图或跨任务串图
```

ZIP 输入额外核对安全解压前图片数、处理后终态数和交付 ZIP 成品数。交付 ZIP 默认不含 source、work、manifest、report 或联系表。

## 四路、重试与降级

- worker 数为 `min(4, 可用槽位, 待处理数)`，每个 worker 内逐张串行。
- 当前任务失败在当前 worker 内至少进行有针对性的重试；记录每次具体失败点。
- 已成功任务不重跑。环境不支持并行或充分重试后仍持续出现同类基础设施错误时降为单路补跑。
- 不切换到用户未授权的图片服务，不索取临时 API key。

## 统一模式

生成并查看联系表，横向检查字体、层级、对齐、边距、间距、色板、标签、商品尺度和形变。偏离风格锁的图片单独重生；只有共享基准错误或用户明确要求时整批重做。报告记录风格锁版本、联系表路径、异常文件和重生结果。

## 报告

批量任务持续更新机器可读 `manifest.json` 和人类可读 `report.md`。最终报告至少包含模式、修改目标、比例、语言、输入/应处理/成功/跳过/失败计数、输出目录、失败原因和交付方式。
