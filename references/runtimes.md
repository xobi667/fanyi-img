# 宿主运行时适配

先检查当前会话实际提供的图片工具，再选择适配方式。核心规则不得硬编码某台电脑的路径、provider、模型或密钥。

## Codex

- 使用 Codex 当前提供的原生图片生成/编辑工具。
- 全新 generate 和默认纯生图 localization：省略所有参考图参数。
- edit：本地目标图先视觉查看，再按工具 schema 传本地参考路径。
- 目标图只有会话图片时，只包含完成当前任务所需的最少最近图片。
- 本地参考路径机制与会话图片机制不得同时使用。
- 每个工具调用只生成当前一个独立成品；成功后立即保存到 manifest 指定路径。

## OpenClaw / Clawdbot

- 使用当前 OpenClaw 会话已经暴露且配置完成的原生图片工具；工具名称和参数以实际 schema 为准。
- 不在 skill 中指定 Gemini、Nano Banana、OpenAI API 或其他固定 provider。
- generate 和默认 localization 不传图片参考；edit 仅在工具明确支持时传目标图和角色。
- 工具只返回远端附件时，使用当前宿主合法的附件保存能力写入任务目录；无法落盘时记录失败，不能伪造本地结果。

## 其他 AgentSkills 宿主

- 只有在当前会话确实存在图片生成/编辑能力时执行。
- 将通用任务映射到宿主工具的 prompt、参考图和输出字段；不猜测不存在的参数。
- 无图片能力、参考图不全或附件不可访问时，停止相应任务并明确缺失能力。

## 交付

宿主支持附件时按其原生方式交付；不支持时报告本地绝对路径。飞书、Discord、Telegram 等通道规则只在对应工具实际存在时适用，不能写进通用核心流程。
